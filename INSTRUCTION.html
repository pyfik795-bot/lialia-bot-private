Установка и запуск «Ляля Бот»

Полная последовательность для отдельного компьютера: Ubuntu, HAPP VPN, Docker, перенос с флешки, проверка и обслуживание.

Ubuntu 24.04 LTS HAPP TUN / gVisor Docker Compose Локальная панель :8080

Общая схема

На сервере запускаются VPN и приложение. Telegram использует системное VPN-соединение напрямую.

Что работает постоянно

HAPP VPN обеспечивает нужный сетевой маршрут. Docker запускает один контейнер: lialia-bot.

Где хранятся данные

Конфигурация, Telegram-сессия, история и активные сделки находятся в папке LialiaBot, а не внутри образа.

Главное правило: одновременно должен работать только один экземпляр бота. Перед запуском на новом ПК остановите старый.

Перед установкой

Рекомендуемая конфигурация: x86-64, 8 ГБ RAM, SSD 256 ГБ и проводное подключение к роутеру.

Активная сделка: перенос лучше выполнять без открытой позиции. Если позиция есть, не допускайте долгого перерыва в сопровождении и обязательно проверьте её на бирже после запуска.

Установка Ubuntu

Для HAPP с графическим интерфейсом используйте Ubuntu Desktop 24.04 LTS. Систему и проект устанавливайте на SSD.

1

Установите систему

При выборе диска внимательно укажите SSD 256 ГБ. После первого запуска выключите ПК и подключите HDD 500 ГБ обратно.

2

Обновите систему и время

Откройте Terminal сочетанием Ctrl + Alt + T и выполните:

Terminal 
sudo apt update
sudo apt upgrade -y
sudo timedatectl set-timezone Europe/Moscow
sudo timedatectl set-ntp true
3

Настройте питание

Отключите автоматический сон. Экран можно выключать, но сам компьютер не должен засыпать.

SSD используйте для Ubuntu, HAPP, Docker и проекта. HDD — для резервных копий.

Настройка HAPP VPN

HAPP должен подключиться раньше бота. Режим обычного системного прокси недостаточен для Docker-контейнеров.

Установка x64-пакета

Terminal 
cd ~/Downloads
curl -fL -o Happ.linux.x64.deb https://github.com/Happ-proxy/happ-desktop/releases/latest/download/Happ.linux.x64.deb
sudo apt install -y ./Happ.linux.x64.deb

Проверка адреса после подключения

Terminal 
curl https://api.ipify.org ; echo
Не запускайте бота, если HAPP отключён. После каждой перезагрузки сначала убедитесь, что VPN подключился.

Установка Docker Engine

В Linux нужен Docker Engine с Compose Plugin. Docker Desktop и WSL здесь не используются.

Terminal · официальный репозиторий Docker 
sudo apt update
sudo apt install -y ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

echo "Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Architectures: $(dpkg --print-architecture)
Signed-By: /etc/apt/keyrings/docker.asc" | sudo tee /etc/apt/sources.list.d/docker.sources > /dev/null

sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo usermod -aG docker "$USER"

После последней команды выйдите из учётной записи Ubuntu и войдите снова, затем проверьте:

Terminal 
docker version
docker compose version

Перенос проекта с флешки

Скопируйте всю папку LialiaBot с флешки в домашнюю папку Ubuntu. Не запускайте сервер непосредственно с флешки.

1

Скопируйте папку

Через приложение «Файлы» перенесите папку в «Домашняя». Итоговый путь должен быть /home/ваше_имя/LialiaBot.

2

Защитите секретные файлы

Команды ограничат чтение конфигурации и Telegram-сессии текущим пользователем.

Terminal 
cd ~/LialiaBot
chmod 600 config.py .env
[ -f BOT.session ] && chmod 600 BOT.session
3

Загрузите офлайн-образ

Файл содержит образ приложения.

Terminal 
cd ~/LialiaBot
docker image load --input ./docker-images.tar
Файл .env скрытый. В приложении «Файлы» нажмите Ctrl + H, чтобы увидеть скрытые файлы.

Первый запуск

Последовательность важна: сначала HAPP, затем Docker-контейнеры.

Запуск контейнеров

Terminal 
cd ~/LialiaBot
docker compose up -d --no-build

Подождите около минуты и проверьте состояние:

Terminal 
docker compose ps
docker compose logs --tail=100 app
Нормальный результат: контейнер lialia-bot имеет состояние Running, в Telegram пришло уведомление о старте.

Открытие панели

На самом сервере откройте браузер и перейдите по адресу http://localhost:8080. Панель специально недоступна из интернета и локальной сети.

Контроль после переноса

Быстрый запуск в Windows

Этот вариант нужен, если комплект запускается на Windows 10/11 с установленным Docker Desktop.

PowerShell 
cd C:\LialiaBot
docker image load --input .\docker-images.tar
docker compose up -d --no-build
docker compose ps

Панель: http://localhost:8080. Если PowerShell-скрипт открывается в блокноте, запускайте его явно:

PowerShell 
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\prepare-docker.ps1"

Ежедневная работа

Telegram-бот предназначен для просмотра. Управляющие действия и настройки выполняйте через веб-панель.

ДействиеКоманда
Проверить состояниеdocker compose ps
Показать журнал приложенияdocker compose logs -f app
Последние 200 строкdocker compose logs --tail=200 app
Перезапустить приложениеdocker compose restart app
Остановить всёdocker compose down
Запустить сноваdocker compose up -d --no-build
Флаг -v здесь не требуется: состояние бота хранится в папке проекта.

Правильное выключение сервера

Terminal 
cd ~/LialiaBot
docker compose down
sudo poweroff

Резервные копии

HDD 500 ГБ используйте для копий папки проекта. В копии находятся токены и ключи — доступ к диску должен быть только у владельца.

Полную копию лучше делать, когда нет активных сделок. Для согласованной Telegram-сессии приложение на несколько секунд останавливается.
Пример · замените путь к HDD 
cd ~/LialiaBot
docker compose stop app
sudo tar --exclude='docker-images.tar' -czf "/mnt/backup/lialia-$(date +%F-%H%M).tar.gz" .
docker compose start app

Путь /mnt/backup — пример. Сначала HDD необходимо подключить и смонтировать. Периодически копируйте один архив на отдельную флешку.

Что нельзя удалять

Секреты и авторизация

config.py, .env, BOT.session.

Состояние торговли

active_trades.json, trade_history.json, остальные JSON-файлы.

Решение частых ошибок

СимптомЧто проверить
Сайт не открываетсяОткрывайте его на самом сервере. Выполните docker compose ps и docker compose logs --tail=200 app.
Telegram сообщает ConflictГде-то работает второй экземпляр с тем же токеном. Остановите старый ПК или контейнер.
Кнопки Telegram не появилисьОтправьте боту /start. Проверьте журнал приложения.
Не приходят сигналыПроверьте HAPP, затем docker compose logs --tail=200 app, авторизацию Telegram и список каналов в панели.
Permission denied для DockerВыполните sudo usermod -aG docker "$USER", затем полностью выйдите из Ubuntu и войдите снова.
Ошибка времени BybitПроверьте timedatectl status. Поля NTP service и System clock synchronized должны быть active/yes.

Диагностический набор

Terminal 
cd ~/LialiaBot
docker compose ps
docker compose logs --tail=200 app
timedatectl status

Безопасность

Файл config.py — секретный. В нём находятся ключи биржи, Telegram и пароль панели. Не отправляйте папку проекта незнакомым людям.
